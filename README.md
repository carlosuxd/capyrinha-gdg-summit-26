# 🦫 Capy-Cool Studio - Vector Character Customizer & LATAM Flags

A modern, lightweight, high-performance web application for customizing clothes, footwear, shades, and fur tones for **Capy-Cool** using vector graphics ([`capyrinha.svg`](capyrinha.svg)) and Latin American (LATAM) national flag backgrounds.

## 🚀 Quick Start

To run locally:

```bash
python3 server.py
```

Then open your browser to:
👉 **[http://localhost:8000](http://localhost:8000)**

*(Or open `index.html` directly in any modern browser).*

---

## ✨ Features

### 1. Vector SVG Customizer ⚡
- **Granular Customization**:
  - 🧥 **Hoodie / Outerwear**: Base color picker with real-time 3D highlights, crease shadows, and folds.
  - 🧶 **Drawstrings**: Cord color picker & subtle drop shadows.
  - 🩳 **Pants & Cargo Shorts**: Base color picker with pocket creases and shadows.
  - 👟 **Footwear & Sneakers**: Main color, side stripes style (Rainbow Pride, Monochrome, Clean White, Gold Street), rubber soles, and laces.
  - 🕶️ **Multi-Color Sunglasses**: Rainbow multi-color, custom solid frame color, dark lenses, or hidden (to show friendly eyes).
  - 🦫 **Fur & Skin Tone**: Fur tone, snout muzzle shade, and cute cheek blush.

### 2. LATAM Flags Background System 🌎
- Exclusive selection of **Latin American (LATAM)** country flags:
  - 🇧🇷 Brazil, 🇦🇷 Argentina, 🇨🇴 Colombia, 🇲🇽 Mexico, 🇨🇱 Chile, 🇵🇪 Peru, 🇺🇾 Uruguay, 🇻🇪 Venezuela, 🇪🇨 Ecuador, 🇧🇴 Bolivia, 🇵🇾 Paraguay, 🇨🇷 Costa Rica, 🇵🇦 Panama, 🇬🇹 Guatemala, 🇩🇴 Dominican Republic, 🇨🇺 Cuba, 🇵🇷 Puerto Rico, 🇭🇳 Honduras, 🇸🇻 El Salvador, 🇳🇮 Nicaragua.
- **Sidebar Integration**: Integrated right inside the **Clothes & Colors** tab.
- **Match Outfit Button**: 1-click styling that maps Capy-Cool's hoodie, pants, shoes, and drawstrings to match the nation's team/flag palette.
- **Export Compositing**: Downloaded PNGs, vector SVGs, and Collector Trading Cards automatically render the active flag background and origin stats.

### 3. Presets & Looks
- **Curated Looks**: Classic Streetwear, Fiery Street Skater, Stealth Techwear, Tactical Camo Explorer, Vintage Denim Casual, Lavender Chill, Cyberpunk Neon.
- **Save Custom Looks**: Save and manage your custom creations directly in browser `localStorage`.
- **Randomize Engine**: Instant color inspiration across official streetwear palettes.

### 4. High-Fidelity Exports
- **High-Res PNG**: Crystal clear raster export with optional flag backdrop.
- **Scalable Vector SVG**: Crisp, infinitely scalable vector markup.
- **Streetwear Collector Card**: Stylized 1000x1400 trading card with metadata, flag origin, specs, and color swatches.
- **Copy SVG to Clipboard**: Instant paste into graphic editors or chat.
